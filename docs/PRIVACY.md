# Politique de confidentialité — Extension DoomName

Dernière mise à jour : 15 novembre 2026

## Données traitées

| Donnée | Où elle est stockée | Pourquoi |
|---|---|---|
| Adresse e-mail d'alerte | Stockage du navigateur (`storage.sync`) et base DoomName au moment d'un ajout de surveillance | Envoyer les alertes de disponibilité |
| Nom de domaine vérifié | Envoyé à `www.doomname.com` pour la requête WHOIS ; mis en cache 10 min localement | Afficher le statut du domaine |
| Historique de recherche | Uniquement dans le navigateur (`storage.local`, 8 entrées max) | Proposer les recherches récentes |
| Préférences (thème, options) | Stockage du navigateur | Personnalisation |

## Ce que l'extension ne fait pas

- Aucun script injecté dans les pages visitées.
- Aucun historique de navigation lu ni transmis : seule l'URL de l'onglet actif
  est lue, à la demande, et uniquement pour en extraire le nom de domaine.
- Aucune donnée envoyée à un tiers : la seule destination réseau est
  `https://www.doomname.com`.
- Aucune publicité, aucun traceur, aucune revente de données.

## Suppression

- Vider le cache et l'historique : page de réglages de l'extension.
- Supprimer une surveillance : page de réglages, ou doomname.com.
- Supprimer l'ensemble des données côté serveur : demande de suppression de
  compte depuis doomname.com.
